# AI Cyberbullying Detection System

This project is an AI-based text classification system that detects whether a comment is toxic or safe.

## Features
- NLP-based text processing using TF-IDF
- Logistic Regression model
- Real-time prediction interface using Gradio

## Tech Stack
- Python
- Scikit-learn
- Pandas
- Gradio

## Demo
The model classifies input text into:
- Toxic / Cyberbullying 🚨
- Safe Comment ✅
